# Данные и разрешения

Эта страница описывает опубликованный Release APK 1.4.

- **Специальные возможности:** служба читает выбранные элементы пакета `ru.yandex.yandexnavi`: манёвр, расстояние, улицу, ограничение и дорожные предупреждения. Нажатия и жесты не выполняются.
- **Экранная стрелка:** включается отдельной кнопкой с описанием доступа. На Android 14+ используется временный кадр окна Навигатора; на Android 11–13 — кадр дисплея, только пока Навигатор является активным окном. Анализируется вырезка известного элемента текущей стрелки. Изображения не записываются в файлы, не отправляются по сети или Bluetooth; при смене приложения изображение не используется. Кадр проверяется повторно перед применением результата.
- **Доступ к уведомлениям:** Android выдаёт службе общий доступ, но код выбирает только навигационное уведомление Яндекс Навигатора. Данные остальных приложений не используются.
- **Bluetooth:** используется для поиска выбранного HUD и передачи команд навигации. Адрес выбранного устройства сохраняется в локальных настройках приложения.
- **Геолокация на Android 8–11:** запрашивается как системное условие поиска BLE. Приложение не получает GPS-координаты и не ведёт историю поездок.
- **Фоновая служба и запуск после загрузки:** нужны для ранее включённой передачи на сохранённый HUD и восстановления соединения.
- **Интернет:** Release APK не содержит разрешения `INTERNET`, сетевого сервера или аналитики. Яндекс Навигатор работает со своими разрешениями независимо от этого приложения.
- **Диагностика:** небольшие текстовые снимки состояния находятся в памяти. Сохранение TXT или копирование выполняется только по нажатию пользователя. Диагностика не содержит отдельных полей улиц, координат и изображений; текст доступных описаний навигационных значков может входить в неё.

В исходниках есть проверки, включаемые только при сборке `Debug`: они могут записывать локальные тестовые состояния навигации. Эти команды и файлы проверок не выполняются в опубликованной Release-сборке.
