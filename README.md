# Яндекс HUD — TEYES

**Навигация из Яндекс Навигатора на WiiYii C1 HUD по Bluetooth.** Самостоятельное Android-приложение для магнитол, первоначально разработанное для TEYES CC4. Телефон, отдельный мост и установленный WiiYii HUD Navigator для работы этой сборки не нужны.

**[Скачать APK 1.4](https://github.com/xxXRatJuiceXxx/YandexHUD-TEYES/releases/download/v1.4/YandexHUD-TEYES-Navigator-1.4.apk)** · [Все релизы](https://github.com/xxXRatJuiceXxx/YandexHUD-TEYES/releases) · [Установка](docs/INSTALL.ru.md) · [Если что-то не работает](docs/TROUBLESHOOTING.ru.md)

## Что умеет

- Передаёт повороты, развороты, расстояние до манёвра, улицу, оставшиеся время и расстояние маршрута.
- Читает навигацию с открытого экрана и из фонового уведомления Яндекс Навигатора.
- В версии 1.4 умеет распознавать изображение текущей стрелки, если Навигатор не предоставляет её текстовое описание. Этот режим включается отдельно.
- Показывает доступные предупреждения о камерах, ограничения скорости и дорожные события, в том числе в режиме обзора дороги без маршрута.
- Передаёт простые подсказки полос, когда они доступны в уведомлении.
- Сохраняет выбранный HUD, повторяет подключение после обрыва и восстанавливает ранее включённую передачу после запуска Android.
- Сбрасывает завершённый маршрут; содержит ручной тест стрелок и экспорт диагностики.

## Совместимость

| Компонент | Требование |
| --- | --- |
| Android | 8.0+ для приложения; **11+** для распознавания изображения стрелки |
| Процессор | ARM32 или ARM64 — обе архитектуры в одном APK |
| Навигация | Отдельный **Яндекс Навигатор** (`ru.yandex.yandexnavi`) на той же магнитоле |
| HUD | WiiYii C1 с совместимым BLE-протоколом; обычно отображается как `WYHUD` |
| Bluetooth | BLE/GATT должен быть доступен сторонним приложениям магнитолы |

Приложение не использует Яндекс Карты как источник. Совместимость с другими HUD и прошивками не подтверждена. Отображение зависит от версии и оформления Навигатора: приложение считывает доступный интерфейс, а не официальный API маршрутов.

## Быстрый запуск

1. Скачайте APK из [Releases](https://github.com/xxXRatJuiceXxx/YandexHUD-TEYES/releases/tag/v1.4), передайте на магнитолу по Bluetooth или через USB и установите.
2. Откройте **Яндекс HUD — магнитола**. Разрешите чтение навигации в специальных возможностях и доступ к уведомлениям.
3. Включите HUD, освободите его соединение с телефоном и нажмите **Найти HUD**. Выберите свой `WYHUD`.
4. Для стрелок при открытой карте нажмите **Стрелки с экрана Навигатора → Включить**, затем выключите и снова включите нашу службу специальных возможностей.
5. Откройте Навигатор и запустите автомобильный маршрут. Для работы в фоне разрешите уведомления самому Навигатору и включите его фоновое ведение.

Обновление с 1.0–1.3 устанавливается **поверх**, без удаления приложения: сохранённый HUD и настройки остаются. [Подробная инструкция](docs/INSTALL.ru.md).

## Ограничения

- Названия улиц передаются на C1 **латиницей**, чтобы избежать иероглифов; интерфейс приложения русский.
- Ограничение скорости на HUD остаётся **текстом**, отдельного круглого знака нет.
- Камера появляется, когда Навигатор отдаёт предупреждение с расстоянием. Собственной базы камер и порога оповещения у приложения нет; метка только на карте не считается предупреждением.
- Полосы доступны не во всех режимах. Неизвестные и устаревшие указания скрываются.
- Неоднозначные и неподдерживаемые рисунки, включая неподдерживаемую геометрию кругового движения, не превращаются в случайную стрелку.
- В фоне доступны данные уведомления. Для чтения экранных элементов Навигатор должен быть открыт, а экран включён.
- Автозапуск и восстановление после сна зависят также от ограничений питания прошивки магнитолы.

## Проверки версии 1.4

Пройдены **206** проверок навигации и **147** проверок протокола/восстановления соединения. При разработке выполнены **343** Android-проверки на ресурсах Навигатора 30.7.3 / Android 16.

На телефоне подтверждено распознавание «направо, 300 м» при открытом Навигаторе, с отключёнными текстовым описанием и доступом к уведомлениям: 23 последовательных обновления в портретной и 24 в горизонтальной ориентации. Проверены отключение распознавания и сброс завершённого маршрута. Эти проверки не подтверждают работу на каждой магнитоле; отдельного подтверждения экранного распознавания 1.4 на физической CC4 пока нет.

## Данные и разрешения

Работа выполняется локально. Release APK не запрашивает доступ к интернету и не содержит сервера или аналитики. После отдельного включения экранного распознавания Android предоставляет временный кадр; анализируется область текущей стрелки. Кадры не сохраняются и не передаются на HUD: туда уходят только команды навигации. [Подробнее о данных](docs/PRIVACY.ru.md).
